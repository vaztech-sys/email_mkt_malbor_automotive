# email_mkt_malbor_automotive

Peça de e-mail marketing automotiva da campanha BOGO (conta Malbor),
convertida do export do Figma Make `EMAIL_MKT_Automotive`.

- **[`email/automotive/`](email/automotive/)** — o entregável: `index.html`,
  `plain-text.txt`, `assets/`, `check.mjs`, `build-zip.sh` e o README com as
  instruções de publicação no Mailchimp.
- `assets/raw/` — o export original do Figma, intocado.
- `build/` — scripts que regeneram os assets a partir de `assets/raw/`.

Peça irmã (náutica, conta YachtPro):
`vaztech-sys/email_mkt_malbor_marines` → `email/marines/`.
